幻境武器助手 — 使用说明

版本 0.1.0 | Dalamud API 15 | 适用于《最终幻想 XIV》7.25+

前置依赖： vnavmesh（路径导航）和 Lifestream（跨地图传送）为可选依赖。若未安装，导航按钮会静默失败。

安装

  1. 将 output/Phantom.dll 放入卫月 devPlugins 目录。
  2. 在游戏内输入 /xlplugins 打开卫月插件列表，找到「幻境武器助手」启用。
  3. 输入 /phantom 打开主窗口。

主窗口

顶部工具栏：

  • 启用插件 — 全局开关，关闭后所有追踪和导航停止。
  • 飞行导航 — 勾选后 vnavmesh 使用飞行路径。
  • 悬浮目标 — 显示/隐藏秘影悬浮追踪窗口。
  • 自动标记击杀 — 聊天栏检测到击杀秘影目标时自动勾选。
  • 重置当前阶段进度 — 清空当前 Tab 的所有进度数据。

  • 可重复来源（黯影阶段）— 副本/FATE 等掉落数量参考。

秘影阶段

按地图折叠，每张地图显示：

  • 总进度条（目标 4/4 + FATE 5/5）
  • 金牌 FATE +/- 计数器（上限 5）
  • 4 个目标的勾选框、坐标、导航按钮

秘影悬浮追踪窗口

位于主窗口之外的可拖动小窗口，始终显示当前地图（或手动切换后的地图）的秘影未完成目标。

按钮功能
停止导航取消当前 vnavmesh 导航
<切换到上一张地图（工具提示：切换上一张）
>切换到下一张地图（工具提示：切换下一张）
当返回自动跟随当前地图模式（工具提示：切换到当前地图）
- / +调整金牌 FATE 计数
最近FATE导航到地图上最近的活跃 FATE

右键菜单： 在窗口任意位置右键可打开主窗口、切换飞行/自动标记、关闭悬浮窗。

地图切换逻辑：
  • 默认自动跟随当前所在地图。
  • 点击 < 或 > 进入手动模式，锁定显示指定地图。
  • 点击 当 回到自动模式。

DEBUG 功能

主窗口最后一个 Tab 有三个调试按钮：

  • 读取当前坐标 — 在聊天栏输出 TerritoryType 和玩家世界坐标 Vector3。
  • 测试坐标换算 — 将玩家当前位置转换为地图坐标，并用示例坐标（20.7, 14.3）反向验证世界坐标。
  • 解析地图参数 — 读取当前地图的 MapRowId、SizeFactor、OffsetX/Y。

坐标换算公式

// 地图坐标 → 世界坐标（vnavmesh 使用）
worldCoord = 50 × mapCoord − offset − 102400 / SizeFactor − 50

// 世界坐标 → 地图坐标（Dalamud 内部）
mapCoord = 0.02 × offset + 2048 / SizeFactor + 0.02 × worldCoord + 1

已知问题

  • 坐标数据部分来自外站，可能存在偏差（已在「活着的记忆·永恒杉树精」验证并修正）。
  • 自动标记击杀依赖聊天栏关键词匹配，可能存在误匹配。
  • Lifestream 未安装时导航不会自动跨地图，需玩家手动到达目标区域。
