肝武助手 — 使用说明

版本 0.1.6 | Dalamud API 15 | 适用于《最终幻想 XIV》7.55+

前置依赖： 推荐安装 vnavmesh ≥ 0.7.6.0（路径导航）和 Lifestream ≥ 2.5.4.15（跨地图/都市传送网）。主窗口顶部会显示依赖加载状态。

安装

  1. 在游戏内输入 /xlplugins 打开卫月插件列表。
  2. 点击「卫月设置」→「测试版」→「自定义插件仓库」，添加以下库链：
    3. https://raw.githubusercontent.com/flyrio/TargetSelector/refs/heads/main/TargetSelector.json
  3. 保存后关闭设置，在插件列表中找到「幻境武器助手」并启用。
  4. 输入 /phantom 打开主窗口。

主窗口

顶部工具栏：

  • 启用插件 — 全局开关，关闭后所有追踪和导航停止。
  • 飞行导航 — 勾选后 vnavmesh 使用飞行路径。
  • 悬浮目标 — 显示/隐藏秘影悬浮追踪窗口。
  • 自动标记击杀 — 聊天栏检测到击杀秘影目标时自动勾选。
  • 重置当前阶段进度 — 清空当前 Tab 的所有进度数据。
  • 前往幻境村 — 若已在幻境村则直接步行到目标点；否则使用 Lifestream 回到图莱尤拉主水晶，再通过都市传送网进入幻境村。

秘影阶段

按地图折叠，每张地图显示：

  • 总进度条（目标 4/4 + FATE 5/5）
  • 金牌 FATE +/- 计数器（上限 5）
  • 4 个目标的勾选框、坐标、导航按钮

幻境武器进度

「幻境武器进度」Tab 用于按职业查看已持有的幻境武器阶段。

  • 同步当前角色 — 扫描当前角色背包、兵装库、装备栏，并调用游戏 ItemFinder 补查雇员、鞍囊、投影台等缓存位置。
  • 按职能显示 — 将职业按防护、治疗、近战、远敏、法系分组显示。
  • 显示武器图标 — 开关卡片上的武器图标，关闭后显示更紧凑。
  • 进度按角色 ContentId 分开保存，多角色不会互相覆盖。
  • 骑士会同时匹配主手剑和副手盾。

自动标记

启用「自动标记击杀」后，插件会根据聊天栏文本自动更新秘影进度。

文本类型自动处理
击杀文本包含目标小怪名标记当前区域对应小怪完成
已完成战斗的记忆“迷宫或讨伐任务：某组”中的所有项目标记该迷宫/讨伐任务组全部完成
已完成战斗的记忆“场景探索：尤卡图拉尔”中的所有项目标记奥阔帕恰山、克扎玛乌卡湿地、亚克特尔树海的小怪 4/4 + FATE 5/5
已完成战斗的记忆“场景探索：萨卡图拉尔”中的所有项目标记夏劳尼荒野、遗产之地的小怪 4/4 + FATE 5/5
已完成战斗的记忆“场景探索：无失世界”中的所有项目标记活着的记忆的小怪 4/4 + FATE 5/5
自动标记说明： 场景探索整组完成会直接把对应区域的金牌 FATE 计数设为 5。若只是单个 FATE 完成，仍按当前地图逐次累计，最高 5。

前往幻境村

顶部「前往幻境村」按钮执行以下流程：

  1. 如果当前已在幻境村，区域 ID 为 1278，跳过传送，直接确认 vnavmesh 就绪并步行导航到目标点。
  2. 如果当前不在幻境村，调用 Lifestream.Teleport(216, 0) 回到图莱尤拉主水晶。
  3. 等待进入图莱尤拉，区域 ID 为 1185，并等待 Lifestream.GetActiveAetheryte() == 216，确认当前已处于图莱尤拉主水晶可用范围。
  4. 调用 Lifestream.AethernetTeleportById(239) 进入幻境村。
  5. 等待进入幻境村，区域 ID 为 1278。
  6. 确认 vnavmesh 就绪并能吸附目标点后，步行导航到 (26.98, 0, 11.26)。

该流程不会执行完整 /li occult，不会继续交互新月岛入口或确认副本。若最终导航短时间内未移动，会自动重试，最多 3 次。

秘影悬浮追踪窗口

位于主窗口之外的可拖动小窗口，始终显示当前地图（或手动切换后的地图）的秘影未完成目标。

按钮功能
停止导航取消当前 vnavmesh 导航
<切换到上一张地图（工具提示：切换上一张）
>切换到下一张地图（工具提示：切换下一张）
当返回自动跟随当前地图模式（工具提示：切换到当前地图）
- / +调整金牌 FATE 计数
最近FATE导航到地图上最近的活跃 FATE
导航（目标旁）导航到该目标位置，聊天栏输出提示

右键菜单： 在窗口任意位置右键可打开主窗口、切换飞行/自动标记、关闭悬浮窗。

地图切换逻辑：
  • 默认自动跟随当前所在地图。
  • 点击 < 或 > 进入手动模式，锁定显示指定地图。
  • 点击 当 回到自动模式。

DEBUG 功能

主窗口最后一个 Tab 提供调试按钮：

  • 读取当前坐标 — 在聊天栏输出 TerritoryType 和玩家世界坐标 Vector3。
  • 测试坐标换算 — 将玩家当前位置转换为地图坐标，并用示例坐标（20.7, 14.3）反向验证世界坐标。
  • 解析地图参数 — 读取当前地图的 MapRowId、SizeFactor、OffsetX/Y。
  • 打开Wiki — 打开幻境武器 Wiki 页面。
  • 读取战斗记忆（未完成） — 预留功能，目前只输出提示。

已知问题

  • 坐标数据部分来自外站，可能存在偏差（已在「活着的记忆·永恒杉树精」验证并修正）。
  • 自动标记击杀依赖聊天栏关键词匹配，可能存在误匹配。
  • Lifestream 未安装或未加载时，跨地图传送和「前往幻境村」不可用。
  • vnavmesh 未安装、未加载或当前地图网格未就绪时，坐标导航不可用。
  • 读取游戏内「战斗的记忆」界面同步进度仍是未完成功能，当前需要手动勾选。
